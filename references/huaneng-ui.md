# 华能简历填写：成功路径与故障恢复

实测日期：2026-10-20至21；整理日期：2026-10-22。仅对当次页面有效，恢复前核对实时界面和当前工具文档。

目标是保存个人简历，不是提交职位申请：

```text
https://zhaopin.chng.com.cn/h5/#/pages/previewResume/index?columnId=41&columnStyle=Resume
```

## 模块与记录

- 预览模块标题右侧的编辑按钮进入子表单。实测 DOM 是 `.section-title` 内 `.edit-btn`；先从当前 DOM 确认，再按标题限定，不固定第几个按钮。
- 教育、家庭、工作、活动、奖项、论文为独立模块。先观察已有记录，再在模块自己的“新增”按钮添加下一条，不能仅填第一条或覆盖原记录。
- 一次观察到编辑器异常空白，继续保存提示“简历id不能为空”。从已完整载入的预览模块入口重新进入后，原记录正确载入。此时应保留新填内容、恢复正确上下文，不能把空编辑器当成服务器真实无记录。

## 日期滚轮

- 年、月、日是三列按钮，不是普通可编辑日期框。实测当前浏览器的 AX 原生按钮索引可直接选择树中列出的远年份，再选月、日并确认；无需逐年滚动几十次。
- 月和日都可能叫“05”或“10”，需按三列所属位置区分。使用动态 AX 索引时，每次打开选择器读取新索引；已观察到的选择与确认动作可合批，完整日期在记录末集中回读，首次试填或异常时立即核对。
- 过去对离屏选项使用普通定位器点击出现过未选中或弹层异常关闭；不能把点击返回当日期成功。选择方式以当前工具是否支持为准，不直接赋值隐藏状态或强改 readonly。

## 中文输入与慢桥接

- 曾出现中文重复、尾部拼音；先核对实际 DOM 值。有些 AX 文本只是显示截断，不能误认成存储截断。
- 可用当前工具支持的 `fill`；异常时聚焦、全选、粘贴并正常失焦，再读回实际值。不要同时在多个字段并行输入。
- 单次浏览器方法曾耗时约20秒；含十多步的批次在300秒超时并导致 REPL 绑定丢失。这是历史观测，不要求以后固定拆成小批次：默认整条记录批填并集中核验，仅在新弹层需观察或实测时限不足时拆分，普通文本和已知选项仍合批。
- 超时后重新绑定原标签页，检查最后一条记录。曾超时但记录已经完整输入，不能再新增一次。标签页 ID、浏览器 ID、索引和坐标均不持久化为操作常量。

## 保存反馈

- 教育曾提示“受教育情况至少包含高中学历!”。补齐用户确认的高中、完整日期后，又出现“受教育经历缺失，请核实!”及“去修改 / 仍然保存”。核对当次三段真实经历后，选择“仍然保存”，成功返回个人中心；未为消除提示编造其他学段。
- 短暂提示可能在截取 AX 前消失；实测只读 DOM 的 `van-toast` 文本有助定位原因。不要因此读框架私有对象或浏览器凭据。
- 某些保存点击只有焦点变化、没有返回页面；检查当前对话框、提示、按钮可见位置后再做一次有依据的替代激活。一次实测通过保存按钮的正常 Enter 激活成功。不能推断所有页面都必须双击或必须按 Enter。
- 成功后可能回到原预览，也可能回个人中心。后者从“我的简历”重开，核对保存后的内容；完整度100%仅作辅助，记录数量与文字才是核验目标。

## 头像上传

1. 先读取当前浏览器工具的文件上传文档，找到真实上传/Choose File入口。
2. 在点击前建立 filechooser 等待，再点击入口，向返回的 chooser 提供原图绝对路径。实测接口为 `tab.playwright.waitForEvent('filechooser')` 与 `chooser.setFiles([path])`，未来只用当前文档仍支持的版本。
3. 选择本地原有证件照，保存基本信息，并在预览中核对照片。上传控件选中不等于网站已保存。

当时用户先自行上传，后来明确改为让助手完成，才进行了上传；此历史同意不代表其他目标的长期上传授权。

## 正式文案与历史状态

奖项描述只写正式奖项内容，例如“校级荣誉称号，个人奖项”或“全国性竞赛二等奖，三人团队”；这里只是格式示例，不是候选人的事实。日期补全规则、核验过程和不确定性留在本地，不填入招聘展示字段。

恢复时按当前页面核验记录数量和内容；历史保存、页面完整度和旧授权均不证明本次已投递。个人资料、历史投递记录和截图不随本公共参考发布。
